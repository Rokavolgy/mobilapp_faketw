# Fwitter - Android Social Media App

A social media application for Android that allows users to share and like posts with text and images. Users can create accounts, log in, follow accounts or manage their profiles.
The application updates realtime and should be compatible with the Python version of the application.

## Dependencies

- Java
- Firebase Authentication
- Firebase Firestore
- Firebase Storage or Supabase Edge Function
- Glide
- Lombok

## Requirements

- Android Studio
- Android SDK 21+
- Firebase account

The application can be tried out by cloning the repository and building, then running it on an Android device or emulator.

Note: A Firebase project is required to run the application. The repository has a free one for testing purposes, but it may get disabled later or if it exceeds the free tier limits.
